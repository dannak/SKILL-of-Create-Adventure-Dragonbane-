# Reference Material

Drop Dragonbane source material here. The skill reads every file in this
folder at the start of each session and uses it to:

- Look up monster stat blocks before scaling encounters
- Cite specific rules (conditions, travel, magic) when writing scene mechanics
- Ground setting details (factions, locations, deities) in your actual campaign

## What to add

**Bestiary entries** — plain text or Markdown, one monster per file or
grouped by type. Include at minimum: HP, STR, AGL, INT, WIL, CHA,
Ferocity, Movement, any special abilities, and suggested tactics.

**Rule passages** — excerpts covering anything the adventure might touch:
conditions (Scared, Exhausted, etc.), travel rules, skill challenge
guidelines, magic school restrictions, encumbrance, healing.

**Setting fragments** — factions and their goals, notable locations and
their quirks, deities and their domains, calendar and seasonal events.
Even a few bullet points per topic is enough.

## Format

Any plain text or Markdown file works. Suggested naming:

```
reference/
  bestiary-creatures-of-the-darkwood.md
  bestiary-undead.md
  rules-conditions.md
  rules-travel-and-overland.md
  setting-factions-ravenland.md
  setting-locations-alderstone.md
```

## If this folder is empty

The skill will warn you and offer to continue using general Dragonbane
knowledge. Results will be less precisely sourced but still functional.
