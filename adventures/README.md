# Adventures

Each completed adventure session lives in its own subdirectory:

```
adventures/
  <slug>/
    adventure.md    — spine, opening scene, chapters, climax, denouement
    npcs.md         — NPC roster with motives, secrets, voice notes
    encounters.md   — statted encounters with scaling math
    handouts.md     — player-facing text: rumours, letters, maps
    gm-notes.md     — pacing notes, contingencies, full audit results
```

The skill creates and populates these files automatically during a session.
Do not edit them manually mid-session — wait for a natural pause point.

After a session, these files are safe to edit, archive, or share.
