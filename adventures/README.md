# Adventures

Each adventure the skill creates gets its own subfolder named by slug:

```
adventures/
  iron-crown-ruins/
    adventure.md
    npcs.md
    encounters.md
    handouts.md
    gm-notes.md
  the-pale-ferry/
    adventure.md
    ...
```

## File contents

**`adventure.md`**
Intake summary at the top, then the outline (chapter list with sidetracks),
then each scene expanded with prose, GM beats, mechanical needs, and
encounter references.

**`npcs.md`**
One entry per named NPC: stat line, role in the adventure, immediate goal,
secret, voice/mannerism notes, and which scenes they appear in.

**`encounters.md`**
One entry per encounter: monster roster with scaled stats, scaling math
(party assumptions, threat level, adjustments), expected resource cost
(WP/HP/conditions burned), tactics, and failure modes.

**`handouts.md`**
Player-facing text ready to read aloud or hand over: rumors heard at the
tavern, found letters, inscriptions, map labels, NPC monologues.

**`gm-notes.md`**
Pacing notes, fail-forward paths for every scene, contingency plans if
the party goes sideways, and the full audit results from the last draft
(pass/fail per checklist item with fix notes for any failures).
